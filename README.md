# 职场营销博弈 (Office Marketing Gambit)

## 项目简介

《职场营销博弈》是一款**单人 PVE 职场博弈游戏**，借鉴桌游《血染钟楼》的机制与叙事风格：你作为玩家，孤身一人面对 **8 名本地 AI 角色**的明争暗斗，在合资公司的权力棋盘上权衡、站队、自保。

> **一句话玩法**：你要在 12 天的办公室政治博弈中，借助 256 张职场「情况牌」做出抉择，躲过派系倾轧，活到最后一刻。

游戏完全**离线运行**——AI 由本地内嵌的启发式算法驱动（非 LLM、无联网），数据全部打包进单个 `.exe`，双击即玩，无需安装、无需账号。

## 特性

- 🎭 **单人 PVE 博弈**：1 名玩家 vs 8 名本地 AI，沉浸式办公室政治体验。
- 🧠 **离线启发式 AI**：本地内嵌算法，不依赖网络、不调用大模型，隐私安全。
- 🃏 **256 张情况牌**：12 大类职场情境，每张 4 个选项，组合无穷。
- 🏢 **4 大合资派系**：锐盟 / 衡明 / 星海 / 长安，各有立场与利益。
- 🔁 **12 天 × 6 阶段循环**：节奏紧凑的回合制推进。
- 🗳️ **联席会议日**：第 3/6/9/12 天白盒投票，可动用预算指认或自保。
- 💾 **本地存档**：进度保存在 `saves/` 目录，随时读取。
- 📦 **单文件 exe**：PyInstaller 打包，零依赖，双击即玩。
- 🔧 **数据可热更**：同目录替换 `cards.json` / `tuning.json` 即可调整内容。

## 快速开始

### 方式一：直接运行（推荐给玩家）

1. 从发布页下载 `职场营销博弈.exe`（位于 GitHub Releases 或本地 `dist/` 目录）。
2. **双击** `职场营销博弈.exe`，游戏窗口即会打开。
3. 按界面提示开始新游戏，或读取已有存档。

> 无需安装 Python、无需联网、无需任何配置。

### 方式二：从源码构建（适合开发者 / 想自己打包）

1. 安装 [Python 3.13](https://www.python.org/)。
2. 在项目根目录打开命令行，安装打包工具：
   ```bash
   pip install pyinstaller
   ```
3. 执行打包命令（完整命令见下文「如何构建」）：
   ```bash
   pyinstaller --onefile --noconsole --paths src --hidden-import cards_data --hidden-import tuning_data --name "职场营销博弈" --add-data "design/cards/cards.json;cards.json" --add-data "config/tuning.json;tuning.json" main.py
   ```
4. 打包完成后，在 `dist/` 目录得到 `职场营销博弈.exe`。

### GUI 操作说明（写给第一次玩的你）

- **主菜单**：选择「开始新游戏」或「读取存档」。
- **情况牌**：每阶段会发给你一张职场情境牌（如「背锅」「站队」），阅读描述后从 **4 个选项** 中选择一项。
- **预算 / 招待额度**：界面顶部显示你的「可动用预算」与「招待额度」——**这是你手中的资源，请合理规划**（注意：游戏内严禁「行贿」等措辞，所有资源使用统称为预算 / 招待安排）。
- **联席会议日**：第 3、6、9、12 天会进入「联席会议」，界面公开各方立场，你可**花费预算指认他人或为自己辩护（自保）**。
- **结局**：若你在博弈中出局，将进入「**离职观察者**」结局（以旁观者视角观看后续）；若坚持到终局则按表现结算。
- **存档 / 退出**：随时可在菜单保存进度；冻结态存档位于 `~/Documents/职场营销博弈/saves/`，开发态回退到 exe 同目录 `saves/`。

### 命令行（适合测试）

- 开发态带界面运行：
  ```bash
  python main.py --gui
  ```
- 无界面冒烟测试（`N` 为模拟局数）：
  ```bash
  python main.py --headless N
  ```

## 游戏机制概述

### 角色与职级

游戏内角色分为三个职级层级：**员工 → 中层 → 高层**。AI 角色分布在不同层级，职级影响其在博弈中的权能与信息。

### 四大派系（合资公司）

| 派系代号 | 名称 | 组成 |
|---------|------|------|
| FV_A | 锐盟 | 华锐 · 西盟 |
| FV_B | 衡明 | 中衡 · 明德 |
| FV_C | 星海 | 星海 · 科盛 |
| FV_D | 长安 | 长盛 · 合安 |

每个派系代表一个合资利益共同体，内部有默契、对外有竞争。

### 情况牌

共 **256 张**情况牌，分为 **12 大类**：

`背锅 / 站队 / 竞品 / 绩效 / 汇报 / 团建 / 反腐 / 晋升 / 客户 / 舆情 / 加班 / 会议`

每张牌提供 **4 个选项**，玩家的选择会影响声望、预算与派系关系。

### 12 天循环

游戏以 **12 天** 为一局，每天分为 **6 个阶段** 循环推进。玩家在每天内经历情境抉择、资源调度与关系变化。

### 联席会议日

第 **3 / 6 / 9 / 12** 天为「联席会议日」，采用**白盒投票**机制：

- 各方立场公开可见；
- 玩家可**花费预算**指认可疑对象，或为自己辩护（自保）；
- 投票与指认结果直接影响后续博弈走向与出局判定。

### 结局

- **出局**：若玩家在博弈中被淘汰，进入「**离职观察者**」结局——以旁观者身份观看剩余剧情。
- **坚持到终局**：根据生存天数、预算与派系影响力结算最终评价。

### 经济合规说明

游戏中的「现金」统一称为 **「可动用预算」/「招待额度」**；所有涉及资源往来的描述均使用合规措辞，**严禁出现「行贿」等表述**。

## 如何构建

在**项目根目录**执行以下步骤（需先安装 Python 3.13 与 pyinstaller）：

```bash
# 1. 安装打包工具
pip install pyinstaller

# 2. 执行单文件打包（在根目录运行）
pyinstaller --onefile --noconsole --paths src --hidden-import cards_data --hidden-import tuning_data --name "职场营销博弈" --add-data "design/cards/cards.json;cards.json" --add-data "config/tuning.json;tuning.json" main.py
```

参数说明：

- `--onefile`：打包为单个可执行文件；
- `--noconsole`：运行时不弹出黑色命令行窗口（GUI 应用）；
- `--paths src`：让 PyInstaller 在 `src/` 中查找模块；
- `--hidden-import cards_data --hidden-import tuning_data`：显式声明 PyInstaller 可能漏检的数据模块；
- `--name "职场营销博弈"`：产物命名为中文 exe；
- `--add-data "design/cards/cards.json;cards.json"` / `--add-data "config/tuning.json;tuning.json"`：将牌组数据与调参数据一并打包（Windows 下用 `;` 分隔源与目标路径）。

构建完成后，产物位于 `dist/职场营销博弈.exe`。

## 如何热更数据

游戏在运行时会优先读取 **exe 同目录** 下的数据文件；若同目录存在同名文件，则**覆盖内嵌默认值**。

热更步骤：

1. 准备一份你要替换的 `cards.json`（情况牌）或 `tuning.json`（调参）。
2. 将这两个文件复制到 `职场营销博弈.exe` **所在的同一个文件夹**。
3. 直接双击运行 exe，新数据即时生效。

> 这意味着你无需重新打包 exe，即可调整牌面内容或数值平衡（例如新增 / 修改情况牌、调节概率权重）。请保证 JSON 格式与内嵌文件结构一致。

## 已知问题 / 平衡观察

- **混沌度（chaos）极易触顶 100**：每次冲突牌 +4、泄密 +6、出局 +8，每日仅 −2。随机策略下几乎每局都触顶，使 chaos 信息量偏低——属调参杠杆，可在 `config/tuning.json` 的 `CHAOS` / `CARD_DRAW` 重新标定。
- **随机策略下「离职观察者」结局占多数**：质量门（`python main.py --headless 50`）在 medium / hard / easy / 7 人下 observer 均占多数、且 `win` / `lose` 均有分布（**并非 `lose` 恒为 0**）。随机 Controller 不懂自保，易被投出局；这是「不崩 + 收敛」回归守护，不代表真实玩家（有策略）的平衡分布。
- **评级分布偏 D**：与「观察者多」同源；可由难度曲线与 AI 凶悍度（`DIFFICULTY.ai_aggressiveness`）调节。
- 单文件 exe 体积较大，属 PyInstaller `--onefile` 打包的正常现象，启动稍慢为预期表现。
- 当前版本为试玩阶段（v0.1.0），AI 为启发式规则，非学习型模型。
