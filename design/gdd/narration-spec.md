## 0. 与本稿相关的事实确认（已读代码，供对齐）

> 下列为 engineering-lead 落地时真实引用的字段与既有函数，本稿规格只使用**占位符**，不臆造取值。

- **本次选择增量**（由 choice 与 prev/state 算出，沿用原 `narrationFor` 口径）：
  - `dPerf` = `state.player().performance - prev.performance`
  - `dNet`  = `state.player().network - prev.network`
  - `dInf`  = `state.player().influence - prev.influence`
  - `dEnergy` = `(100 - state.player().stress) - (100 - prev.stress)`（精力增量；`energy = 100 - stress`）
- **全局局势**（全部来自 `state`，非 choice 本地 `faction_trust`）：
  - `state.factionTrust = {FV_A, FV_B, FV_C, FV_D}`（派系议程强弱矩阵）→ argmax 得「领先派系」。
  - `state.chaos`（冲突度 0–100+，本稿仅作可选增强，见 §B 注）。
  - `state.month`（1–60）配合 `monthLabel(state.month).label`（如 `"2027年3月"`）。
  - 各表盘 `state.player().performance / network / influence`（0–100）与 `stress`（0–100，energy=100-stress）。
  - 告急判定：`performance<20` 或 `network<20` 或 `influence<20` 或 `stress>80`（等价于 `energy<20`）。
- **派系立场名（本旁白专用，须与 `cards.js` 的 `consequence` 派系立场名同源）**：
  - `FV_A`=抢单派 / `FV_B`=维稳派 / `FV_C`=上位派 / `FV_D`=降压派 —— 这四个词在 `consequence` 玩家可见文案中出现 **1986 次**（抢单派538 / 维稳派624 / 上位派482 / 降压派342），是玩家认知里的派系叫法。
  - ⚠️ **禁用 `factionAlias(f)`**：该函数返回的是**合资公司别名**（`FV_A`=锐盟 / `FV_B`=衡明 / `FV_C`=星海 / `FV_D`=长安，见 `web/tuning.js`），在卡面文案中出现 **0 次**，与本旁白语义无关。落地常量 `NARR_FACTION_SIDE = {FV_A:"抢单派",...}`（以 `factionAlias` 仅作兜底）。映射方向已核实实卡（M02c3：`faction_trust` `FV_A:3` 最高 → 「（抢单派会更信你）」）。
  - `monthLabel(m)` 返回 `{ year, mon, career, label }`，`label` 形如 `"2027年3月"`（**7 字**；`2027年12月` 为 **8 字**），从 2026年7月 起算、共 60 月。

# A. 核心原则

1. **形态 = 一句话**：用**逗号**连接、整体是连贯的一句，**不写分号、不拆多句、不分段**。
2. **长度目标 ≈ 30 字（弹性区间 25–42 字，含标点；实测均值 39.3 字）**：
   - 玩家原始反馈是「多数只 10–15 字一句，太简单」，目标是**明显拉长、一句话说清局面**。因需聚合「本次变化 + 全局局势」四段，四段全满约 47 字（§D 实测 String.length）；在默认 `NARR_MAX_LEN=42` 下经 §C.6 逐级降级，实战区间稳落 **[25, 42]**、均值 **39.3 字**（40 局 9348 条）。
3. **内容聚合（四段，至少含前两项）**：
   - `{主变化句}`：本次选择的主表盘变化（取绝对值最大维度）。
   - `{领先派系句}`：当前全局领先派系（或势均力敌）。**必含**。
   - `{告急句}`：有无表盘亮红灯。**必含**。
   - `{月进度句}`：月进度（第三项，择一/简短带过，但建议常驻以体现「时间推移」）。
4. **语气（与现有 flavor/desc/consequence 统一）**：暗场烛光、职场暗战；白话、让玩家**秒懂「现在局面怎样、我处于什么位置」**；不学王权式言简意赅，不端着。复用既有「你……」第二人称叙述口吻。
5. **确定性**：仍由 `state` 字段组合生成，**无随机**。纯兜底池的 2–3 句也按 `state.month` 确定性选取（见 §C.5）。

# B. 模板结构（占位符 + 降级规则）

## B.1 主模板（engineering-lead 替换为真实 state 取值）

```
{主变化句}，{领先派系句}，{告急句}，{月进度句}。
```

- 四段以中文逗号连接，句末句号收尾，整体**一句话**。
- 当某些字段无意义时，对应占位符**降级为中性短句**（见下），保证总长仍落在 25–42 字且不突兀。

## B.2 各占位符降级规则（无信号时如何兜底）

| 占位符 | 正常形态 | 降级形态（无意义时） | 触发条件 |
|------|------|------|------|
| `{主变化句}` | 见 §C.1（~13–16 字） | 中性短句（见 §C.4，~14 字） | 本次无显著变化（`maxAbs < SIGNIFICANT`） |
| `{领先派系句}` | `眼下{派系别名}势头最盛`（~9 字） | `几家派系还在暗里拉锯`（~10 字） | 全局派系势均力敌（见 §C.2） |
| `{告急句}` | `{表盘名}已亮红灯（，你得留神）`（~6–11 字） | `盘面暂时无虞`（~6 字） | 无任何表盘亮红灯 |
| `{月进度句}` | 见 §C.3（~12–14 字） | 可省略或仅留 `{label}`（~7 字） | 若总长超限，优先压缩本段（见 §C.6） |

> **注（state.chaos 可选增强）**：若主理人希望体现「冲突度」，可在 `{月进度句}` 后追加可选短 clause `暗流越来越急`（当 `state.chaos > 60`）或 `风浪暂时压住了`（当 `state.chaos < 20`）。属**可选**，启用会拉长成句，默认不开启，以免过载。

# C. 分支模板（engineering-lead 直接落地硬口径）

> 本节为可抄实现的硬口径：装配逻辑 + 各段生成表 + 长度自控。伪代码仅作说明，落地写进 `web/game.js` 的 `narrationFor`（替换原 167–208 行）。

## C.0 装配逻辑（总控）

```
// 前置：算 dPerf/dNet/dInf/dEnergy（同原 narrationFor）
// 1) 主变化维度：取 |值| 最大者；同大按 performance>network>influence>energy 定序
dims = [("performance",dPerf),("network",dNet),("influence",dInf),("energy",dEnergy)]
dom = argmax(|值|, 定序如上);  maxAbs = |dom.value|
SIGNIFICANT = 5           // 主变化句触发阈值（原版用 8，此处降到 5 以更常出"主变化"）

// 2) 全局信号
lead = argmax(state.factionTrust);  spread = lead.val - 次大.val
clearLead = (spread >= 3) && (lead.val > 0)     // 明确领先
alarms = [ 表盘名 | 该表盘亮红灯 ]               // perf<20||net<20||inf<20||stress>80

// 3) 分支
if (maxAbs >= SIGNIFICANT) {
    s1 = 主变化句(dom)                 // §C.1 真实维度句
} else if (clearLead || alarms.length>0) {
    s1 = 主变化中性句()                // §C.4
} else {
    return 纯兜底句(state.month % 3)   // §C.5（无显著变化 且 无领先 且 无告急）
}
s2 = 领先派系句(clearLead, lead)       // §C.2
s3 = 告急句(alarms)                    // §C.3
s4 = 月进度句(state.month)             // §C.3
return s1 + "，" + s2 + "，" + s3 + "，" + s4 + "。"   // 一句话
```

## C.1 `{主变化句}`（取绝对值最大维度，~13–16 字）

- 维度定序（与 `quadrant-system.md` §B.2 一致）：`performance > network > influence > energy`。
- 档位：`强`（|d| ≥ 8）/ `中`（5 ≤ |d| < 8）。`maxAbs < 5` 不走此表（见 §C.4/§C.5）。

| 维度 | 方向 | 档位 | 文案（占位符已替换，{dim} 为维度名） |
|------|------|------|------|
| 业绩 `performance` | 涨 | 强(≥8) | 业绩的红线上，你又往前拱了一寸。 |
| 业绩 | 涨 | 中(5–7) | 业绩缓过劲，数字往上抬了些。 |
| 业绩 | 跌 | 强(≤−8) | 手里那点业绩，又被划走一截。 |
| 业绩 | 跌 | 中(−7..−5) | 业绩这波没顶住，略微下挫。 |
| 精力 `energy` | 缓过 | 强(≥8) | 一口气松下来，肩膀终于不僵了。 |
| 精力 | 缓过 | 中(5–7) | 紧绷的弦松了半格，人轻松些。 |
| 精力 | 透支 | 强(≤−8) | 你揉了揉太阳穴，今天是不眠夜。 |
| 精力 | 透支 | 中(−7..−5) | 精力又被抽走一截，有点发虚。 |
| 声望 `influence` | 涨 | 强(≥8) | 你这回露了脸，风评一下蹿起来。 |
| 声望 | 涨 | 中(5–7) | 这手处理得漂亮，风评小涨一截。 |
| 声望 | 跌 | 强(≤−8) | 你这一出，声望当场掉了不少。 |
| 声望 | 跌 | 中(−7..−5) | 话没说圆，口碑悄悄凉了半截。 |
| 人脉 `network` | 涨 | 强(≥8) | 人脉这一下活络开来，路子宽了。 |
| 人脉 | 涨 | 中(5–7) | 多搭了几句话，人缘又热乎些。 |
| 人脉 | 跌 | 强(≤−8) | 你这一手，把几个人脉线掐断了。 |
| 人脉 | 跌 | 中(−7..−5) | 几处关系有点松动，得防着点。 |

> 风格说明：保留原 `narrationFor` 的「你……」白话口吻与暗场隐喻（红线/太阳穴/风评/人脉线），并**扩写到 ~13–16 字**。原版只有 dPerf/dEnergy 正负 + dInf 正，本表补全「声望跌 / 人脉涨跌」四档，覆盖更全。

## C.2 `{领先派系句}`（基于全局 `state.factionTrust` argmax）

- 计算 `lead = argmax(state.factionTrust)`，`spread = lead.val − 次大.val`。
- **明确领先**（`spread ≥ 3` 且 `lead.val > 0`）→ `眼下{派系别名}势头最盛`
  - 例：`眼下抢单派势头最盛` / `眼下维稳派势头最盛` / `眼下上位派势头最盛` / `眼下降压派势头最盛`。
- **势均力敌**（否则）→ `几家派系还在暗里拉锯`。
- 派系立场名映射（**与 `cards.js` 的 `consequence` 派系立场名同源，禁用 `factionAlias`**——后者返回合资公司别名 锐盟/衡明/星海/长安，与本旁白无关）：`FV_A`→抢单派 / `FV_B`→维稳派 / `FV_C`→上位派 / `FV_D`→降压派。落地常量 `NARR_FACTION_SIDE`（见 §0）。

> 注意：此处用**全局** `state.factionTrust`（概括全局局势），**不是** choice 本地 `faction_trust`。原版按 choice 本地增量拼句是用户明确说"没概括全局"的根因，本稿改为全局 argmax。

## C.3 `{告急句}` 与 `{月进度句}`

### 告急句（基于 `state.player()` 四表盘 + stress）

- 亮红灯判定：`performance<20` 或 `network<20` 或 `influence<20` 或 `stress>80`（stress>80 即 `energy<20`，表盘名用「精力」）。**阈值放宽至 `<30` 属设计口径变更，需主理人拍板（见 §C.7）。**
- 表盘中文名：`performance`→业绩 / `network`→人脉 / `influence`→声望 / `stress>80`→精力。
- **有告急**：
  - 单灯 → `{表盘名}已亮红灯`（~6 字）。
  - 双灯 → `{表盘A}与{表盘B}已亮红灯`（~10 字，如 `业绩与人脉已亮红灯`）。
  - **三灯及以上** → 总述 `盘面红灯一片`（~6 字，与「盘面暂时无虞」同主语同句式；三/四灯并列会达 12–15 字顶破预算，故改用总述）。
  - 可视长度预算补 `，你得留神`（见 §C.6）。
- **无告急** → `盘面暂时无虞`（~6 字）。

### 月进度句（基于 `monthLabel(state.month).label` + `state.month/60`）

`{label}` 由 `monthLabel` 提供，形如 `2027年3月`（**7 字**；`2027年12月` 为 **8 字**）。本句按长度预算**逐级降级**（非一步到底），以保留领起词语感：

| 区间（month） | 完整形态（含进展短语） | 中间形态（领起词+label，默认 ≤42 下常见） |
|------|------|------|
| 初期 `[1, 6]` | `{label}，你才刚进场。` | 裸 `{label}`（如 `2026年7月`） |
| 发展 `[7, 24]` | `到了{label}，棋局渐明。` | `到了{label}`（如 `到了2027年9月`） |
| 过半 `[25, 48]` | `转眼{label}进度过半。` | `转眼{label}`（如 `转眼2027年3月`） |
| 末段 `[49, 60]` | `熬到{label}，收尾在即。` | `熬到{label}`（如 `熬到2029年6月`） |

- **降级链**：完整形态 → 中间形态（领起词+`{label}`；初期无专属领起词故即裸 `{label}`）→ 裸 `{label}` → 省略（当主变化/领先/告急已很满时整段省去）。
- ⚠️ **完整形态在默认 `NARR_MAX_LEN=42` 下基本不出现**（四段全满约 47 字，见 §D）。若希望完整形态常驻，将 `NARR_MAX_LEN` 调到 **48** 并同步放宽本文档长度口径（见 §C.6 / §C.7）。默认保持 ≤42。

## C.4 `{主变化中性句}`（Path B：无显著变化但全局有信号）

当 `maxAbs < SIGNIFICANT` 但 `clearLead` 或 `alarms` 非空时，主变化段用中性短句，再照常接 `{领先派系句}/{告急句}/{月进度句}`：

- `这一步落子，盘面没太大动静，`（~14 字，逗号保留以便连接）

> 此句吸收原 `byArch` 兜底「局面静悄悄，但没人真的松手」的暗场口吻，扩写为中性过渡句。

## C.5 `{纯兜底句}`（Path：无显著变化 且 无领先 且 无告急）

当 `maxAbs < SIGNIFICANT` 且**非** `clearLead` 且 `alarms` 为空 → **直接返回一整句通用局势句**（不走四段装配）。从下列 3 句按 `state.month % 3` **确定性**选取（保证可复现、随月推进有变化）：

1. `茶水间的风声没停过，你在这盘棋里还没真正站稳脚跟。`
2. `烛火没灭，局也没散，你只是还没看清这屋里谁在落子。`
3. `有人记住了你这一手，可眼下这盘棋还看不出谁占上风。`

> 三句均 ~25 字、暗场语气，承接原 `byArch` 单行的隐喻风格（茶水间/烛火/落子/记住你这一手），长度合规且不与四段模板冲突。

## C.6 长度自控（逐级降级，保证一句话不爆）

`NARR_MAX_LEN` 默认 **42**（实测输出区间 **[25, 42]**，平均 **39.3 字**，40 局 9348 条）。超出时**逐级**压缩（非一步到底），优先级从高到低：

1. `{告急句}` 去掉 `，你得留神` 后缀（11→6 字）；三/四灯已由 §C.3 总述为 `盘面红灯一片`，不再并列。
2. `{月进度句}` 降级链：完整形态 → 领起词+`{label}`（如 `转眼2027年3月`）→ 裸 `{label}`（如 `2027年3月`）→ 省略（整段省去）。**不一步降到裸 label**，以保留领起词语感。
3. `{领先派系句}`：明确领先可由 `眼下{派系}势头最盛` 缩为 `{派系}占上风`（9→6 字）；势均力敌可由 `几家派系还在暗里拉锯` 缩为 `几派还在拉锯`（10→6 字）。
4. `{主变化句}`：若处「强」档（16 字），超限时可退化为对应「中」档（~14 字）——一般不必，前三步已够压。

> 实测结论：四段全满约 **47 字**，经上述逐级降级稳回 **[25, 42]**。玩家感知目标（比原 10–15 字明显更长、一句话说清局面）已达成。若将 `NARR_MAX_LEN` 调到 48，则完整月进度形态可常驻，但平均字数会进一步上移（见 §C.7）。

## C.7 待主理人拍板的两处设计口径（design-strategist 建议 + 实战数据）

1. **告急阈值 `<20` vs `<30`**（实战：40 局 9348 条旁白中仅 **58 条**含告急句 = **0.6%**）。
   - 成因：`perf/net/inf<20` 很少发生——表盘触边即软重置回 50，常年中位，故「盘面暂时无虞」几乎常驻。
   - 影响：当前告急句几乎不承重，旁白对「你正危险」的提示极少。
   - **design-strategist 建议**：暂保持 `<20`（与 `reigns_layer` 触边 / `balance.md` 数值语义一致，避免把正常中位误报为红灯）；若主理人希望红色警示更频繁，可放宽到 `<30`（属平衡/经济口径变更，需同步复核 `balance.md`）。**本稿默认 `<20`，未改。**
2. **`NARR_MAX_LEN` 42 vs 48**（见 §C.3 / §C.6）。
   - **design-strategist 决定（默认）**：保持 **42**。理由：用户原始诉求是「从 10–15 字扩到 ~30 字」，39.3 字均值已充分满足；完整月进度形态（「进度过半/收尾在即」）是锦上添花，label 本身已传达时间，压缩后语感仍由领起词保住。若主理人坚持完整形态常驻，则调 48 并放宽本文档口径至 48。
   - 实测分布（健康）：明确领先 **83.5%** / 势均力敌 **5.6%** / 纯兜底 **10.9%**。

# D. 长度合规示例（填好占位符后的成句）

> 下列为 `narrationFor` 在真实 state 下的输出样例，证明「一句话 + 本次变化 + 全局局势 + ~30 字」。括号内为估算字数（含标点）。

**示例 1｜业绩强涨 + 抢单派领先 + 无告急 + 过半**
- 完整形态：`业绩的红线上，你又往前拱了一寸，眼下抢单派势头最盛，盘面暂时无虞，转眼2027年3月进度过半。` → **String.length = 47 字**
- 默认口径（≤42，月进度压缩为「领起词+label」）：`…，转眼2027年3月。`（落入 [25,42] 区间）

**示例 2｜精力强透支 + 势均力敌 + 业绩告急 + 初期**
- 完整形态：`你揉了揉太阳穴，今天是不眠夜，几家派系还在暗里拉锯，业绩已亮红灯，2026年7月，你才刚进场。` → **String.length = 47 字**
- 默认口径：同上（月进度已是最简「{label}，…」），落入 [25,42] 区间。

**示例 3｜声望中涨 + 上位派领先 + 无告急 + 末段**
- 完整形态：`这手处理得漂亮，风评小涨一截，眼下上位派势头最盛，盘面暂时无虞，熬到2029年6月收尾在即。` → **String.length = 46 字**
- 默认口径：`…熬到2029年6月。`（落入 [25,42] 区间）

**示例 4｜人脉强跌 + 降压派领先 + 精力告急 + 发展期**
- 完整形态：`你这一手，把几个人脉线掐断了，眼下降压派势头最盛，精力已亮红灯，到了2027年9月，棋局渐明。` → **String.length = 47 字**
- 默认口径：同上（月进度已最简），落入 [25,42] 区间。

**示例 5｜纯兜底（无显著变化 + 无领先 + 无告急，month%3=0）**
- `茶水间的风声没停过，你在这盘棋里还没真正站稳脚跟。` → **String.length = 25 字**

> 说明：示例 1–4 的「完整形态」字数按 **String.length 实测**（含标点与数字，`{label}` 计 7–8 字）。在当前默认 `NARR_MAX_LEN=42` 实现下，月进度句的「进展短语」会被逐级压缩掉（§C.6 第 2 步），故实战输出为「默认口径」压缩版；但四段总字数分布不变——实测区间 **[25, 42]**，平均 **39.3 字**。
>
> 结论：全部成句为**一句话、逗号连接、覆盖「本次变化 + 领先派系 + 告急 + 月进度」**，满足用户「追加到 ~30 字、一句话说明当前情况」的诉求。「完整四段形态」上界约 47 字（需 `NARR_MAX_LEN ≥ 48` 才常驻，见 §C.7）。

# E. 与现有风格的兼容性说明

**结论：不冲突，且语气同源、可无缝统一。**

| 对比项 | 现有（`quadrant-system.md` §B / 卡面） | 本旁白规格 | 是否冲突 |
|------|------|------|------|
| 语气 | 暗场烛光、职场暗战、白话「你……」第二人称（如 desc「你选择蛰伏守成：…」、consequence「风评见涨，业绩有望往上走（抢单派会更信你）。」、flavor「手册越厚，套得越紧」） | 同暗场、同「你……」口吻、同隐喻体系（红线/太阳穴/风评/人脉线/茶水间/落子） | 否，同源 |
| 信息密度 | §B 已要求「代价当场可见」「白话让玩家知道在干啥」 | 一句话聚合「本次变化 + 全局局势」，正是把该原则延伸到**结算后旁白** | 否，是补充不是推翻 |
| 派系命名 | `cards.js` 的 `consequence` 玩家文案用 抢单派/维稳派/上位派/降压派（1986 次）；`factionAlias` 返回合资公司别名 锐盟/衡明/星海/长安（卡面 0 次） | 本稿建 `NARR_FACTION_SIDE` 与 `consequence` 派系立场名同源，**禁用 `factionAlias`** | 否，命名一致 |
| 确定性 | desc/consequence/text 全模板化、可复现 | 本旁白同样由 `state` 字段组合、无随机（纯兜底也按 `month%3` 确定） | 否，机制一致 |
| 长度 | consequence 多为 1 句 15–25 字；原 `narrationFor` 仅 10–15 字 | 扩到 ~30 字一句话，**正是用户诉求的修复点** | 否，是针对性改进 |

**需要主理人拍板的一点（非冲突）**：原 `narrationFor` 用 choice 本地 `faction_trust` 拼派系句，本稿改为**全局 `state.factionTrust` argmax**——这是用户「要概括全局局势」的直接要求，与 §B 的「派系附注」不矛盾（§B 的 consequence 仍讲本次选项的派系影响，本旁白讲全局领先派系，二者互补）。若主理人坚持旁白也用本地 `faction_trust`，可把 §C.2 的 `state.factionTrust` 换回 `choice.faction_trust`，其余不变。
