# 《职场营销博弈》游戏概念文档（Game Concept）

- 文档版本：v0.1（Phase 1 概念定稿候选）
- 作者：文策渊（design-strategist）
- 项目铁律：Python 实现 / PyInstaller 单文件 .exe；AI 为规则-启发式引擎（非 LLM）；256 张情况牌一步到位
- 一句话定位：**单人 PVE 的「隐藏派系 × 职场政治」卡牌博弈游戏** —— 你是一家集团里某家合资公司的暗线代表，用 12 天时间在会议、饭局、汇报与背刺中完成派系隐藏目标，同时不让别人看穿你是谁。

---

## 1. 高概念（High Concept）

> 《血染钟楼》的隐藏身份与昼夜紧张感，脱去中世纪外壳，装进中国式职场：
> **"处刑"变成联席会议的优化名单，"恶魔"变成暗中吞并对手份额的合资公司，"占卜"变成背景调查与酒桌套话。**

- 玩家扮演 1 名角色（员工 / 中层领导 / 高层领导三档之一），归属 4 家合资公司（JV）之一。
- 场上另有 8 名 AI 角色，各有隐藏派系与隐藏目标；派系归属对玩家**不可见**，只能通过行为、投票、口径矛盾去推断。
- 每一张「情况牌」是一次公开的职场情境；玩家和 AI 在同一情境下做选择，选择即**表态**，表态即**泄露信息**。
- 核心张力：**你必须行动才能推进目标，但每次行动都在暴露自己。**

## 2. 设计支柱（Design Pillars）

支柱是评审一切系统的唯一标尺；任何机制若不服务于至少一条支柱，直接砍掉。

| # | 支柱 | 内涵 | 反面案例（禁止） |
|---|------|------|------------------|
| P1 | **表态即暴露（Every Choice Leaks）** | 所有选择都被至少一个 NPC 观察并写入其信念模型；玩家的最优解永远要在「推进目标」与「保持模糊」之间权衡 | 出现"零成本万能选项"（既推进目标又不留痕） |
| P2 | **信息不对等是核心资源** | 情报（谁属于哪家 JV、谁的目标是什么）比数值更值钱；声望/现金的最终用途是**买情报与买人**| 把游戏做成纯数值滚雪球 |
| P3 | **没有中立的第 5 天**（时钟压迫） | 12 天硬期限 + 每 3 天一次联席会议淘汰，逼迫玩家从观望转向下注 | 允许玩家全程摸鱼仍能达成目标 |
| P4 | **可读的坏人（AI 必须可被推理）** | AI 是白盒启发式：性格向量 + 效用函数 + 派系偏好 + 有界随机扰动。玩家熟练后应能**预测**而非**猜**AI 行为 | 用不可解释的随机或黑箱 LLM 输出 |
| P5 | **职场荒诞的真实感** | 文本层要让玩家笑着叫疼：背锅、站队、口径统一、酒桌顺序、优化名单 | 幻想式办公室、无痛喜剧化 |

## 3. MDA 分析

### 3.1 Mechanics（机制层：规则与资源）

| 机制 | 说明 |
|------|------|
| 昼夜推进 | 12 天，每天：晨会 → 白天 3 张情况牌 → 午间密谈 1 次 → 夜间行动 1 次 → 日结 |
| 情况牌引擎 | 256 张牌，12 类主题，按 tier/category/派系局势加权抽取；每牌 ≥4 选项，含玩家选项与 AI 选项 |
| 三资源 | influence 声望（0-100）、stress 压力（0-100）、cash 现金/可动用资源（万元，可负） |
| 隐藏派系 | 4 家 JV，每家 1 个隐藏目标（吞并份额 / 守住客户 / 上位夺权 / 平稳落地） |
| 信任矩阵 | 9×9 trust[i][j] ∈ [-100,100]，由公开选择与私下密谈更新 |
| 信念模型 | 每个 NPC 维护 belief[j][faction] 概率分布（启发式加权，非贝叶斯严格解） |
| 夜间能力 | 员工=情报（八卦/翻记录）；中层=施压/护人；高层=背景调查/调岗 |
| 联席会议 | 第 3/6/9/12 天，全员投票产出「优化名单」1 人 → 出局；玩家可发言、串票、买票 |
| 阵营目标判定 | 每个目标有明确阈值公式（见 balance.md），第 12 天日终统一判定 |

### 3.2 Dynamics（动态层：涌现的玩法）

- **口径漂移侦测**：AI 因派系偏好在相似牌上做出不一致选择 → 玩家发现"这人上次护 B 家客户，这次却砍 B 家预算"→ 推断其真实派系。
- **虚假旗帜（False Flag）**：玩家故意选对自己派系不利的选项，用 3-5 点声望换取"我不是那家人"的洗白。
- **代理人战争**：玩家不直接对抗，而是喂信息让两家 JV 的 NPC 互相举报（反腐类牌是首选武器）。
- **压力管理死亡螺旋**：高压 → 选项判定失败率上升 → 更依赖激进选项 → 更暴露 → 被投票出局。
- **投票市场**：临近联席会议，cash 与人情的边际价值飙升，形成"最后一天的贿选行情"。
- **信任透支**：反复背刺短期收益高，但 trust 全面转负后无人与你密谈 → 情报断供 → 后期目标无法达成。

### 3.3 Aesthetics（美学层：目标体验，MDA 八感取 4）

| 优先级 | 美学 | 具体感受 |
|--------|------|----------|
| 1 | **Challenge（挑战）** | 12 天内解一道信息不完整的推理题 |
| 2 | **Fellowship / 伪同盟（Fellowship 的黑色变体）** | 与 AI 建立"我们是一伙的"错觉，然后目睹或实施背叛 |
| 3 | **Discovery（发现）** | 拼出 9 人的派系地图与隐藏目标 |
| 4 | **Narrative（叙事）** | 每局生成一段"我如何在集团活下来"的可复述故事（结局卡 + 关键节点回放） |

**明确不追求**：Sensation（感官刺激）、Submission（消磨时间）。这不是放置游戏。

## 4. 核心循环（Core Loop）

```
[晨会：公开局势播报 + 今日议程] 
      ↓
[白天：抽 3 张情况牌] → 玩家选项 → AI 依效用函数同场选择 → 公开结算（所有人看见结果）
      ↓
[午间密谈：选 1 名角色私聊] → 交换/伪造情报，更新双方 trust
      ↓
[夜间行动：使用 tier 能力] → 私密信息或私密影响
      ↓
[日结：资源结算 / 压力检定 / 传闻生成] → (每 3 天) 联席会议投票淘汰
      ↓
第 12 天日终 → 派系目标判定 → 结局
```

**单局时长目标**：25-40 分钟。**单牌决策时长**：15-40 秒。

## 5. 范围分层（Scope Tiers）

### MVP（必须做，否则游戏不成立）
1. 12 天昼夜循环 + 白天 3 牌 + 日结
2. 256 张情况牌数据全量接入（cards.json）+ 抽牌加权与去重
3. 4 家 JV + 4 类隐藏目标 + 阈值判定
4. 三档角色（员工/中层/高层）能力差异
5. 启发式 AI：性格向量 + 效用函数 + 派系偏好 + 扰动
6. trust 矩阵 + belief 模型（简化版：只对"是否同派系"打分）
7. 联席会议投票淘汰（4 次）
8. 胜负判定 + 4 类结局文本
9. 3 档难度（易/中/难）
10. 纯文本/极简 GUI 界面（Tkinter 或 curses 风格），单文件 .exe 可跑

### Target（目标层，MVP 稳定后立即做）
11. 午间密谈系统（含说谎选项与被验证机制）
12. 夜间能力完整版（三档各 3 个技能）
13. 传闻/舆情传播系统（信息在 NPC 间扩散、失真）
14. 关键节点回放（结局时展示"你其实被谁盯了 5 天"）
15. 存档/读档 + 局内日志导出

### Vision（愿景层，明确排除在本期外）
16. 玩家自定义卡牌编辑器（读外部 cards.json 即可支持，成本低，可提前）
17. 多集团战役模式（跨局继承声望）
18. 成就系统与结局图鉴
19. 中英双语文本层
20. 立绘与语音（当前视觉锚点为图形化极简）

## 6. 视觉锚点关键词（与 `design/art/art-bible.md` 对齐）

> **一致性说明**：本节初稿曾提出"冷调玻璃幕墙 + 荧光灯"方向，与已定稿的《美术圣经》"暗场烛光（炭黑/深棕 + 烛光橙）"存在基调冲突。
> **策划侧决定：以《美术圣经》的暗场烛光为唯一主基调**（它更贴近《血染钟楼》的密室低语气质，也更省资产成本）；本节保留的是**设计侧的语义锚点**，不覆盖色彩规范。
> 仍需美术侧同步的三项，已在回传中提交主理人（选项区需容纳 4 个选项 / 12 类 category 图标缺 8 个 / 派系命名统一）。

- **整体基调（采纳美术圣经）**：`暗室低语` `烛光晕染` `酒过三巡` `炭黑深棕 + 烛光橙 + 派系色爆发` `体面下的算计`
- **设计侧补充锚点**：`OA 审批单` `会议纪要页` `红头文件与印章` `优化名单表格` `工牌与部门色条`
- **UI 隐喻**：卡牌 = 内部邮件 / OA 审批单 / 会议纪要页；资源条 = 绩效仪表盘；投票 = 优化名单表格
- **角色表达**：不画写实立绘；用**工牌卡片 + 剪影头像 + 部门色条**表达身份；派系归属用"未知"占位符（问号水印）
- **昼夜表达**：白天=会议室投影白幕的冷光片区（暗底上的一块亮区）；夜间=整屏压暗，仅留台灯烛光橙一圈
- **张力表达**：压力升高时 UI 边缘出现细微噪点与偏色；背刺发生时全屏一帧红章"已归档"
- **禁用**：卡通萌化、赛博朋克霓虹、欧美企业插画风（Corporate Memphis）

## 7. 目标玩家与心理模型

### 7.1 目标玩家
- 核心：25-40 岁、有 3 年以上职场经验、玩过《血染钟楼》/狼人杀/《Reigns》/《这是我的战争》一类抉择游戏的中文玩家。
- Bartle 映射：**Killer（政治博弈）40% + Explorer（推理派系与牌库）35% + Achiever（结局与目标达成）20% + Socializer 5%**（单机 PVE，社交感由 AI 伪同盟提供）。

### 7.2 自我决定论三感（SDT）

| 需求 | 满足方式 | 反向红线 |
|------|----------|----------|
| **自主（Autonomy）** | 每牌 ≥4 个**语义差异明显**的选项（顺从/背刺/结盟/自保/揭发/观望/花钱/硬扛），且没有全局最优解；派系目标可用多条路径达成（正面业绩 or 抹黑对手 or 结盟分票） | 出现主导策略（如"永远选背刺"最优）→ 立即调平衡 |
| **胜任（Competence）** | AI 白盒可推理：熟练玩家能预测 NPC 选择；提供"局势播报"与"你已确认的信息"面板，让技能成长可见 | 结局由隐藏随机数决定 → 剥夺胜任感 |
| **关联（Relatedness）** | 密谈系统建立一对一羁绊；NPC 会记住玩家帮过他（reciprocity 项），会在投票时救你一次；结局文本回顾关系 | AI 无记忆、每天重置态度 |

### 7.3 心流与难度曲线（12 天）

| 天数 | 玩家状态 | 设计手段 | 目标情绪 |
|------|----------|----------|----------|
| D1-D2 | 摸清规则与人 | 只出 tier=any/employee 的低烈度牌；NPC 扰动大、行动温和 | 好奇、轻松试错 |
| D3 | 第一次联席会议 | 强制投票，必须表态 | 第一次心跳加速 |
| D4-D6 | 信息积累与初次下注 | 引入 category=站队/竞品/反腐 的高烈度牌；NPC aggressiveness +0.1 | 紧张、算计 |
| D6 | 第二次会议 + 中期事件（集团巡视/舆情） | 全局资源冲击，打断稳态 | 危机感 |
| D7-D9 | 派系目标进入冲刺 | 高层牌与晋升牌集中出现；NPC 开始主动背刺玩家 | 高压、必须下注 |
| D9 | 第三次会议（通常玩家最危险） | 若玩家 influence 低则被针对 | 峰值紧张 |
| D10-D11 | 收网 | 触发目标进度提示（"你距离吞并还差 2 个客户"） | 目标清晰的冲刺快感 |
| D12 | 终局会议 + 判定 | 一次性揭示所有人派系与目标 | 恍然大悟 + 复盘欲 |

难度体现在**信息噪声**与**AI 攻击性**，而不是在数值上给玩家上税（详见 balance.md 难度档位）。

## 8. 关键设计风险（提交主理人）

| 风险 | 描述 | 缓解方案 |
|------|------|----------|
| R1 主导策略 | 若"背刺"类选项收益普遍最高，游戏退化为无脑背刺 | 背刺附带 trust 全场衰减与 stress 累积；trust<-40 后密谈/情报断供 |
| R2 认知过载 | 9 名 NPC × 4 派系 × 信任矩阵，玩家记不住 | 提供"关系笔记"面板（玩家手动标记 + 已确认信息自动记录）；MVP 可降至 7 名 NPC |
| R3 AI 可读性 vs 不可预测性 | 白盒 AI 玩 3 局就被摸透 | 性格向量每局随机生成 + 派系与角色档位随机绑定 + 扰动温度随难度变化 |
| R4 256 张牌的重复感 | 12 类 × 21 张，同类牌易同质化 | 每类内部按"烈度 1-3"与 tier 分层；抽牌器同类同 tier 24 小时内不重复；已抽牌本局不回抽 |
| R5 无 LLM 的文本单调 | 静态文本反复见 | 结算文案模板化组合（角色名 + 派系代称 + 结果程度词），MVP 后补 |
